    Arama ayarları · Google Books anahtarı

    Google Books, anahtarsız aramalarda çoğu zaman kota hatası veriyor; o zaman sonuçlar yalnızca Open Library’den gelir ve yeni Türkçe baskılar az çıkar. Ücretsiz bir anahtarla arama çok daha iyi çalışır. Anahtar yalnızca bu tarayıcıda saklanır, JSON yedeğine ve CSV’lere girmez.

    1. Google Cloud Console’da Books API sayfasını aç ve etkinleştir.
    2. “Kimlik bilgileri” bölümünden bir API anahtarı oluştur; istersen yalnızca Books API ile sınırla.
    3. Anahtarı aşağıya yapıştırıp kaydet.
